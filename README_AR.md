# عدسة الحديث

محرك بحث فوري للأحاديث النبوية الصحيحة مع نظام ترجمة متعدد اللغات

## المميزات

- 🔍 **بحث فوري**: البحث في أكثر من 10,000 حديث من صحيحي البخاري ومسلم
- 🌍 **ترجمة متعدد اللغات**: ترجمة فورية لأكثر من 100 لغة باستخدام الذكاء الاصطناعي
- 📖 **حديث اليوم**: حديث يومي محدد بالتاريخ
- 📚 **أحاديث ذات صلة**: اقتراح أحاديث مشابهة باستخدام الذكاء الاصطناعي
- 🎨 **واجهة أنيقة**: تصميم فاخر يجمع بين جمال المخطوطات الإسلامية والحداثة
- 📱 **متجاوب**: يعمل على جميع الأجهزة
- 🔊 **بحث صوتي**: البحث بالصوت باللغة العربية
- 📖 **وضع القراءة**: وضع قراءة خالٍ من التشتت مع تحكم في حجم الخط
- 🔗 **مقارنة الترجمات**: مقارنة الترجمات جنبًا إلى جنب
- 💾 **السجل والمحفوظات**: حفظ الأحاديث المفضلة وتاريخ البحث
- 🖼️ **مشاركة كصورة**: مشاركة الحديث كصورة جميلة

## التثبيت

### المتطلبات

- Node.js 18 أو أحدث
- npm أو yarn

### الخطوات

1. استنساخ المستودع:
```bash
git clone <repository-url>
cd Web7mod
```

2. تثبيت المكتبات:
```bash
npm install
```

3. إعداد قاعدة البيانات:
```bash
npm run setup
```

4. إعداد ملف البيئة:
```bash
cp .env.example .env
```

5. إضافة مفتاح Gemini:
افتح ملف `.env` وأضف مفتاح Google Gemini API:
```
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash
```

للحصول على مفتاح Gemini:
1. اذهب إلى [Google AI Studio](https://makersuite.google.com/app/apikey)
2. سجل الدخول بحساب Google
3. أنشئ مفتاح API جديد
4. انسخ المفتاح وأضفه إلى ملف `.env`

### اختياري: تفعيل DeepL

للحصول على ترجمات عالية الجودة للغات المدعومة، يمكنك إضافة مفتاح DeepL:

```
DEEPL_API_KEY=your_deepl_api_key_here
DEEPL_ENABLED=true
```

- مفاتيح DeepL المجانية تنتهي بـ `:fx`
- بدون مفتاح DeepL، سيتم استخدام Gemini لجميع الترجمات

## التشغيل

### وضع التطوير (مع إعادة التشغيل التلقائي):
```bash
npm run dev
```

### وضع الإنتاج:
```bash
npm start
```

### تشغيل الاختبارات:
```bash
npm test
```

### إعادة إعداد قاعدة البيانات:
```bash
npm run setup
```

## الاستخدام

1. افتح المتصفح واذهب إلى: `http://localhost:3000`
2. ابحث عن أي حديث بالعربية أو أي لغة أخرى
3. انقر على الحديث لعرض التفاصيل والترجمات
4. استخدم اختصار `Ctrl+K` (أو `Cmd+K` على Mac) للوصول السريع

## الاختصارات

- `Ctrl/Cmd + K`: فتح لوحة الأوامر
- `Escape`: إغلاق النوافذ المنبثقة
- `Enter`: البحث

## الأمان

- مفاتيح API لا تُرسل إلى العميل
- الحماية من هجمات XSS
- تقييد CORS على localhost
- حد معدل الطلبات
